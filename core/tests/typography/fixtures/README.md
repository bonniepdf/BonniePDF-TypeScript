# Typography fixtures

## Colour emoji fixtures

`TwemojiMozilla-Fixture.ttf` and `NotoColorEmoji-Fixture.ttf` are small fontTools 4.63.0 subsets covering `emoji.json`. Their fixture family names identify modified fonts. The JSON pins their SHA-256 hashes, source hashes and sizes. The upstream Twemoji Mozilla and Noto Color Emoji licences are included alongside the fonts. The bitmap fixtures also exercise independently constructed packed indexed PNGs with transparent, partial and omitted alpha entries. Expected fixture data is never generated by the rendering engine.

## RTL fixtures

`rtl.json` pins layout positions, mixed logical text, and independent HarfBuzz glyph IDs, clusters, advances and offsets for Arabic and Hebrew. The unmodified Noto Sans Arabic and Noto Sans Hebrew fonts are SHA-256 pinned; their OFL copyright and licence files are alongside them. Expected glyph data comes from the independent reference corpus, never the implementation under test.
